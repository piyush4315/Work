# Start here

This folder **is** the GitHub project.

| Do this | How |
|---|---|
| Run the app | Open `ScrapSale_Pro.html` in a browser |
| Put it on GitHub | See commands in `README.md` |
| Change the product later | Edit `ScrapSale_Pro.html` only (keep it one file) |
| Keep *your* lots | In the app: **Export → JSON** — HTML does not store typed lots |
| Hand to another AI | Send this folder + that JSON + `docs/HANDOFF.md` |

```
scrapsale-pro/
├── START_HERE.md
├── README.md
├── LICENSE
├── .gitignore
├── index.html              ← convenience launcher
├── ScrapSale_Pro.html      ← full application
├── data/

│   └── Combined_Bid_Sheet 17.08.2026 (2).xlsx
└── docs/

    └── FORMULAS.md
```
